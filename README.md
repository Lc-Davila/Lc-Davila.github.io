# Nima - Ecossistema de Adoção

O **Nima** é uma plataforma de adoção de animais focada em garantir o bem-estar e a segurança dos pets através de tecnologia, unindo software e hardware (IoT).

## O Problema e a Solução
*   **Problema:** Superlotação em abrigos, devoluções traumáticas por falta de compatibilidade entre o perfil do animal e do adotante, e fuga de pets recém-adotados.
*   **Solução:** Um ecossistema que realiza match comportamental preciso e fornece ferramentas de monitoramento pós-adoção através de tags NFC nas coleiras e módulos IoT (ESP32) integrados ao aplicativo.

## Público-Alvo
*   ONGs e Protetores Independentes.
*   Futuros Tutores buscando pets compatíveis.
*   Tutores Atuais que buscam rastreamento e segurança.

## Tecnologias Utilizadas
*   React e Vite (Landing Page)
*   CSS Puro
*   JavaScript, Node.js e React Native
*   Supabase (SQL)
*   Hardware IoT (ESP32, C/C++)
